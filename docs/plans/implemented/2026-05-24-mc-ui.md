# MissionControl UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1 of the MissionControl operator UI — a React SPA bound to the existing MC Worker via Workers Assets, covering auth, org/member/PAT management, agents/connectors/projects CRUD, and read-only tasks + events views.

**Architecture:** Same Worker serves `/api/v1/*` (Hono) and a Vite-built SPA (`web/dist/`) via the Cloudflare Vite plugin's Workers Assets binding. SPA uses TanStack Router (file-based), TanStack Query (cursor pagination), shadcn/ui + better-auth-ui (shadcn registry). Schemas extracted to `src/schemas/` shared with the UI via a tsconfig path alias.

**Tech Stack:** React 18, Vite, `@cloudflare/vite-plugin`, TanStack Router + Query + Virtual, shadcn/ui, better-auth-ui, Tailwind v4, sonner, Vitest + RTL + MSW + Playwright, ESLint, dependency-cruiser.

**Spec:** `docs/specs/2026-05-24-mc-ui-design.md`

### Task 0.1: Cloudflare Email Service — RESOLVED

**Decision (locked 2026-05-24):** use **Cloudflare Email Service** (CES). Per the official docs at `https://developers.cloudflare.com/email-service/get-started/send-emails/`:

- **Binding** declared in `wrangler.jsonc` as:
  ```jsonc
  "send_email": [{ "name": "EMAIL", "remote": true }]
  ```
- **API:** `await env.EMAIL.send({ to, from, subject, html, text })` — POJO, no MIME construction needed.
- **Setup:** the sender domain must use Cloudflare DNS; CES adds MX + SPF + DKIM + DMARC records during onboarding. Documented in `services/mission-control/README.md` under "Email setup."
- **Transactional sends** (welcome / verification / password reset / magic link) are explicit listed use cases — recipients are not pre-verification-restricted (that limitation is specific to the older Email Routing `send_email` binding).

Feeds Task 1.7 (the `email.ts` adapter — concrete CES implementation, not the stub).

```ts
// services/mission-control/src/schemas/common.ts
//
// Browser-safe schemas. ONLY imports allowed: zod.
// Enforced by ESLint rule in services/mission-control/eslint.config.js (Task 1.5).
import { z } from 'zod';

/** IdSlug: prefixed entity id matcher. `IdSlug('t_').parse('t_abc123')`. */
export const IdSlug = (prefix: string) =>
  z.string().regex(new RegExp(`^${prefix.replace(/[.*+?^${}()|[\\]\\\\]/g, '\\$&')}[a-zA-Z0-9_-]+$`));

/** RFC 3339 timestamp (the API serializes integers to RFC 3339 per master spec). */
export const IsoTimestamp = z
  .string()
  .refine((s) => !Number.isNaN(Date.parse(s)), { message: 'Invalid RFC 3339 timestamp' });

/** Task status values per master API spec §"Task lifecycle". */
export const TaskStatus = z.enum([
  'pending', 'ready', 'in_progress', 'blocked', 'completed', 'failed', 'cancelled',
]);
export type TaskStatus = z.infer<typeof TaskStatus>;

/** Member role values per master API spec §"Role model". */
export const MemberRole = z.enum(['owner', 'admin', 'member']);
export type MemberRole = z.infer<typeof MemberRole>;

/** Principal type values. */
export const PrincipalType = z.enum(['pat', 'agent', 'connector']);
export type PrincipalType = z.infer<typeof PrincipalType>;

/** Standard cursor-paginated response wrapper. */
export const Paginated = <T extends z.ZodTypeAny>(item: T) =>
  z.object({
    data: z.array(item),
    next_cursor: z.string().nullable(),
  });

/** API error envelope per master spec §"Error model". */
export const ErrorEnvelope = z.object({
  error: z.object({
    code: z.string(),
    message: z.string(),
    details: z.unknown().optional(),
  }),
});
export type ErrorEnvelope = z.infer<typeof ErrorEnvelope>;

/** Soft-delete columns present on most user-mutable rows. */
export const SoftDeleteFields = z.object({
  deleted_at: IsoTimestamp.nullable(),
  deleted_by_type: z.enum(['user', 'agent', 'connector', 'system']).nullable(),
  deleted_by_id: z.string().nullable(),
});
```

```ts
// services/mission-control/src/middleware/validate-responses.ts
import type { MiddlewareHandler } from 'hono';
import { z } from 'zod';
import { Agent, AgentListResponse, AgentCreateResponse, AgentRotateKeyResponse } from '../schemas/agents.ts';
import { Connector, ConnectorListResponse, ConnectorCreateResponse, ConnectorRotateKeyResponse } from '../schemas/connectors.ts';
import { Project, ProjectListResponse } from '../schemas/projects.ts';
import { Task, TaskListResponse, TaskDetailResponse } from '../schemas/tasks.ts';
import { CommentListResponse } from '../schemas/comments.ts';
import { EventListResponse } from '../schemas/events.ts';
import { ExternalRefListResponse } from '../schemas/external-refs.ts';
import { MeResponse } from '../schemas/me.ts';

/**
 * Route→schema map. Add entries here when new routes/responses land.
 * The middleware looks up the active route's pattern + method and validates
 * the outgoing body against the schema in dev only — logs on mismatch.
 */
const ROUTE_SCHEMAS: Array<{ method: string; pattern: RegExp; schema: z.ZodTypeAny }> = [
  { method: 'GET',  pattern: /^\/api\/v1\/me$/,                                  schema: MeResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/agents$/,                              schema: AgentListResponse },
  { method: 'POST', pattern: /^\/api\/v1\/agents$/,                              schema: AgentCreateResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/agents\/[^/]+$/,                       schema: Agent },
  { method: 'POST', pattern: /^\/api\/v1\/agents\/[^/]+\/rotate-key$/,           schema: AgentRotateKeyResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/connectors$/,                          schema: ConnectorListResponse },
  { method: 'POST', pattern: /^\/api\/v1\/connectors$/,                          schema: ConnectorCreateResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/connectors\/[^/]+$/,                   schema: Connector },
  { method: 'POST', pattern: /^\/api\/v1\/connectors\/[^/]+\/rotate-key$/,       schema: ConnectorRotateKeyResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/projects$/,                            schema: ProjectListResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/projects\/[^/]+$/,                     schema: Project },
  { method: 'GET',  pattern: /^\/api\/v1\/tasks$/,                               schema: TaskListResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/tasks\/[^/]+$/,                        schema: TaskDetailResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/tasks\/[^/]+\/comments$/,              schema: CommentListResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/events$/,                              schema: EventListResponse },
  { method: 'GET',  pattern: /^\/api\/v1\/external_refs$/,                       schema: ExternalRefListResponse },
];

export const validateResponses: MiddlewareHandler = async (c, next) => {
  await next();
  // Only validate successful JSON responses
  if (c.res.status < 200 || c.res.status >= 300) return;
  const ct = c.res.headers.get('content-type') ?? '';
  if (!ct.includes('application/json')) return;

  const url = new URL(c.req.url);
  const entry = ROUTE_SCHEMAS.find((e) => e.method === c.req.method && e.pattern.test(url.pathname));
  if (!entry) return;

  // Clone the response so we can read its body without consuming it for the client.
  const clone = c.res.clone();
  let body: unknown;
  try { body = await clone.json(); } catch { return; }

  const result = entry.schema.safeParse(body);
  if (!result.success) {
    console.warn('[validate-responses] schema drift', {
      method: c.req.method,
      path: url.pathname,
      issues: result.error.issues.slice(0, 5), // cap noise
    });
  }
};
```

```ts
import { render } from '@react-email/render';
import {
  EmailVerificationEmailTpl,
  ResetPasswordEmailTpl,
  MagicLinkEmailTpl,
} from './templates';

export type SendEmailArgs = { to: string; subject: string; html: string; text: string };

/**
 * Single provider implementation. To swap providers, edit ONLY this function.
 * Provider chosen per Task 0.1 pre-flight (CES / MailChannels / Resend).
 *
 * Dev/test mode (no EMAIL_FROM env var): logs the would-be email and returns
 * without sending. This lets test environments (e.g. cloudflare:test) exercise
 * the full sign-up → verify-email flow without configuring a real provider.
 */
export async function sendEmail(env: { EMAIL_FROM?: string; EMAIL?: any; RESEND_API_KEY?: string }, args: SendEmailArgs): Promise<void> {
  if (!env.EMAIL_FROM) {
    // Dev/test: no provider configured. Log-only.
    console.warn('[email] EMAIL_FROM not set — skipping send.', { to: args.to, subject: args.subject });
    return;
  }
  if (!env.EMAIL) {
    // Production has EMAIL_FROM but no EMAIL binding — misconfiguration. Surface loudly.
    throw new Error('[email] EMAIL_FROM is set but the EMAIL binding is missing — check wrangler.jsonc');
  }
  // Cloudflare Email Service (Task 0.1 decision).
  // Docs: https://developers.cloudflare.com/email-service/get-started/send-emails/
  const result = await env.EMAIL.send({
    to: args.to,
    from: env.EMAIL_FROM,
    subject: args.subject,
    html: args.html,
    text: args.text,
  });
  if (!result?.messageId) {
    throw new Error(`[email] CES send returned no messageId: ${JSON.stringify(result)}`);
  }
}

export async function deliverVerificationEmail(env: any, params: { user: { email: string; name?: string }; url: string }) {
  const html = await render(EmailVerificationEmailTpl({ url: params.url, userName: params.user.name ?? params.user.email }));
```

```ts
  AgentListResponse, Agent, AgentCreateBody, AgentPatchBody, AgentCreateResponse, AgentRotateKeyResponse,

  ConnectorListResponse, Connector, ConnectorCreateBody, ConnectorPatchBody, ConnectorCreateResponse, ConnectorRotateKeyResponse,

  Project, ProjectListResponse, ProjectCreateBody, ProjectPatchBody,

  Task, TaskListResponse, TaskDetailResponse, TaskListQuery,
} from '@mc/schemas/tasks';
import type { CommentListResponse } from '@mc/schemas/comments';
import type { EventListResponse, EventListQuery } from '@mc/schemas/events';
import type { ExternalRefListResponse } from '@mc/schemas/external-refs';
import type { MeResponse } from '@mc/schemas/me';

export class ApiError extends Error {
  constructor(public status: number, public code: string, public details?: unknown, public requestId?: string) {
    super(`${status} ${code}`);
  }
}

function qs(params: Record<string, unknown>): string {
  const sp = new URLSearchParams();
  for (const [k, v] of Object.entries(params)) {
    if (v === undefined || v === null) continue;
    if (Array.isArray(v)) v.forEach((x) => sp.append(k, String(x)));
    else sp.set(k, String(v));
  }
  const s = sp.toString();
  return s ? `?${s}` : '';
}

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`/api/v1${path}`, {
    ...init,
    headers: { 'content-type': 'application/json', ...(init?.headers ?? {}) },
  });
  const requestId = res.headers.get('x-request-id') ?? undefined;
  if (!res.ok) {
    const body = await res.json().catch(() => ({} as any));
    throw new ApiError(res.status, body?.error?.code ?? 'unknown', body?.error?.details, requestId);
  }
  if (res.status === 204) return undefined as T;
  return res.json();
}

export const api = {
  me:      () => request<MeResponse>('/me'),

  agents: {
    list: (q: { cursor?: string; limit?: number } = {}) => request<AgentListResponse>(`/agents${qs(q)}`),
    get: (id: string) => request<Agent>(`/agents/${id}`),
    create: (b: AgentCreateBody) => request<AgentCreateResponse>('/agents', { method: 'POST', body: JSON.stringify(b) }),
    patch: (id: string, b: AgentPatchBody) => request<{ agent: Agent }>(`/agents/${id}`, { method: 'PATCH', body: JSON.stringify(b) }),
    rotateKey: (id: string) => request<AgentRotateKeyResponse>(`/agents/${id}/rotate-key`, { method: 'POST' }),
    delete: (id: string) => request<void>(`/agents/${id}`, { method: 'DELETE' }),
  },

  connectors: {
    list: (q: { cursor?: string; limit?: number } = {}) => request<ConnectorListResponse>(`/connectors${qs(q)}`),
    get: (id: string) => request<Connector>(`/connectors/${id}`),
    create: (b: ConnectorCreateBody) => request<ConnectorCreateResponse>('/connectors', { method: 'POST', body: JSON.stringify(b) }),
    patch: (id: string, b: ConnectorPatchBody) => request<{ connector: Connector }>(`/connectors/${id}`, { method: 'PATCH', body: JSON.stringify(b) }),
    rotateKey: (id: string) => request<ConnectorRotateKeyResponse>(`/connectors/${id}/rotate-key`, { method: 'POST' }),
```

```tsx
// services/mission-control/web/src/components/app-shell/theme-provider.tsx
import { createContext, useContext, useEffect, useState, ReactNode } from 'react';

type Theme = 'light' | 'dark' | 'system';
const ThemeCtx = createContext<{ theme: Theme; setTheme: (t: Theme) => void }>({ theme: 'system', setTheme: () => {} });

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setThemeState] = useState<Theme>(() => (localStorage.getItem('mc-theme') as Theme | null) ?? 'system');

  useEffect(() => {
    const root = document.documentElement;
    const apply = (t: Theme) => {
      const dark = t === 'dark' || (t === 'system' && matchMedia('(prefers-color-scheme: dark)').matches);
      root.classList.toggle('dark', dark);
    };
    apply(theme);
    if (theme === 'system') {
      const mq = matchMedia('(prefers-color-scheme: dark)');
      const listener = () => apply('system');
      mq.addEventListener('change', listener);
      return () => mq.removeEventListener('change', listener);
    }
  }, [theme]);

  const setTheme = (t: Theme) => { localStorage.setItem('mc-theme', t); setThemeState(t); };
  return <ThemeCtx.Provider value={{ theme, setTheme }}>{children}</ThemeCtx.Provider>;
}

export const useTheme = () => useContext(ThemeCtx);
```

```ts
// services/mission-control/web/src/lib/error-messages.ts
import { ApiError } from './api';

export function messageFor(err: unknown): string {
  if (!(err instanceof ApiError)) return 'Something went wrong.';
  const idHint = err.requestId ? ` (request_id: ${err.requestId})` : '';
  switch (err.code) {
    case 'agent.has_active_tasks':
      return `Cannot delete — agent has active tasks.${idHint}`;
    case 'connector.has_active_tasks':
      return `Cannot delete — connector has active tasks.${idHint}`;
    case 'auth.invalid':
      return 'Session expired. Please sign in again.';
    case 'auth.role_insufficient':
      return 'You do not have permission to do that.';
    case 'task.invalid_transition':
      return 'That task status change is not allowed.';
    case 'pool.binding_missing':
      return 'Service unavailable. Please try again shortly.';
    case 'idempotency.conflict':
      return 'A request with that idempotency key already exists.';
    default:
      return `${err.code}${idHint}`;
  }
}
```

```tsx
export class ErrorBoundary extends Component<{ children: ReactNode }, { error: unknown }> {

  render() {

}
```

```tsx
export const Route = createFileRoute('/onboarding/create-org')({ component: CreateOrgRoute });

function slugify(s: string) {
  return s.toLowerCase().trim().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '');
}

function CreateOrgRoute() {
  const [name, setName] = useState('');
  const [slug, setSlug] = useState('');
  const [submitting, setSubmitting] = useState(false);
  const navigate = useNavigate();

  const onSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setSubmitting(true);
    try {
      await authClient.organization.create({ name, slug: slug || slugify(name) });
      await authClient.getSession({ query: { disableCookieCache: true } });

    }

      <form onSubmit={onSubmit} className="w-full max-w-md p-8 bg-card rounded-lg shadow space-y-4">
        <h1 className="text-2xl font-bold">Create your organization</h1>
```

```tsx
          </DialogDescription>
        </DialogHeader>
        <div className="bg-muted p-3 rounded font-mono text-sm break-all">{props.keyValue}</div>
        <DialogFooter>
          <Button variant="outline" onClick={copy}>Copy</Button>
          <Button onClick={props.onClose}>Done</Button>
```

```tsx
// services/mission-control/web/src/components/agents/agent-detail.tsx
import { useState } from 'react';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { useNavigate, Link } from '@tanstack/react-router';
import { api, ApiError } from '../../lib/api';
import { Button } from '../ui/button';
import { Input } from '../ui/input';
import { Label } from '../ui/label';
import { AlertDialog, AlertDialogAction, AlertDialogCancel, AlertDialogContent, AlertDialogDescription, AlertDialogFooter, AlertDialogHeader, AlertDialogTitle, AlertDialogTrigger } from '../ui/alert-dialog';
import { KeyRevealModal } from '../shared/key-reveal-modal';
import { messageFor } from '../../lib/error-messages';
import { toast } from 'sonner';

export function AgentDetail({ agentId }: { agentId: string }) {
  const qc = useQueryClient();
  const navigate = useNavigate();
  const [keyReveal, setKeyReveal] = useState<string | null>(null);

  const { data: agent, isLoading } = useQuery({
    queryKey: ['agents', agentId],
    queryFn: () => api.agents.get(agentId),
  });

  const [name, setName] = useState('');
  const [description, setDescription] = useState('');

  const saveMut = useMutation({
    mutationFn: () => api.agents.patch(agentId, { name: name || undefined, description: description || undefined }),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ['agents'] });
      toast.success('Agent updated');
    },
    onError: (err) => toast.error(messageFor(err)),
  });

  const rotateMut = useMutation({
    mutationFn: () => api.agents.rotateKey(agentId),
    onSuccess: (res) => setKeyReveal(res.key),
    onError: (err) => toast.error(messageFor(err)),
  });

  const deleteMut = useMutation({
    mutationFn: () => api.agents.delete(agentId),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ['agents'] });
      navigate({ to: '/agents' });
      toast.success('Agent deleted');
    },
    onError: (err) => {
      if (err instanceof ApiError && err.code === 'agent.has_active_tasks') {
        const ids = (err.details as any)?.task_ids as string[] | undefined;
        toast.error(
          <span>
            Cannot delete — has active tasks:{' '}
            {ids?.map((id) => (
              <Link key={id} to="/tasks/$taskId" params={{ taskId: id }} className="underline">{id}</Link>
            )).reduce((p, c) => <>{p}, {c}</>)}
          </span>
        );
      } else {
        toast.error(messageFor(err));
      }
    },
  });

  if (isLoading) return <p>Loading…</p>;
  if (!agent) return <p>Not found.</p>;

  return (
    <div className="space-y-6 max-w-2xl">
      <h1 className="text-2xl font-bold">{agent.name}</h1>
      <p className="text-muted-foreground">Kind: {agent.kind} • Created {new Date(agent.created_at).toLocaleString()}</p>

      <section className="space-y-4">
        <h2 className="text-lg font-semibold">Edit</h2>
        <div><Label htmlFor="name">Name</Label><Input id="name" defaultValue={agent.name} onChange={(e) => setName(e.target.value)} /></div>
        <div><Label htmlFor="desc">Description</Label><Input id="desc" defaultValue={agent.description ?? ''} onChange={(e) => setDescription(e.target.value)} /></div>
        <Button onClick={() => saveMut.mutate()} disabled={saveMut.isPending}>Save</Button>
      </section>

      <section className="space-y-4">
        <h2 className="text-lg font-semibold">Danger zone</h2>
        <div className="flex gap-2">
          <Button variant="outline" onClick={() => rotateMut.mutate()} disabled={rotateMut.isPending}>Rotate key</Button>
          <AlertDialog>
            <AlertDialogTrigger asChild><Button variant="destructive">Delete agent</Button></AlertDialogTrigger>
            <AlertDialogContent>
              <AlertDialogHeader>
                <AlertDialogTitle>Delete this agent?</AlertDialogTitle>
                <AlertDialogDescription>Soft-deletes the agent. Will fail if active tasks are assigned.</AlertDialogDescription>
              </AlertDialogHeader>
              <AlertDialogFooter>
                <AlertDialogCancel>Cancel</AlertDialogCancel>
                <AlertDialogAction onClick={() => deleteMut.mutate()}>Delete</AlertDialogAction>
              </AlertDialogFooter>
            </AlertDialogContent>
          </AlertDialog>
        </div>
      </section>

      <KeyRevealModal open={!!keyReveal} keyValue={keyReveal ?? ''} onClose={() => setKeyReveal(null)} title="New agent key (old key valid 5 more minutes)" />
    </div>
  );
}
```

```tsx
// services/mission-control/web/src/routes/accept-invitation.tsx
import { createFileRoute, useNavigate } from '@tanstack/react-router';
import { useEffect, useState } from 'react';
import { z } from 'zod';
import { authClient } from '../lib/auth-client';
import { toast } from 'sonner';
import { messageFor } from '../lib/error-messages';

export const Route = createFileRoute('/accept-invitation')({
  validateSearch: z.object({ token: z.string() }),
  component: AcceptInvitationRoute,
});

function AcceptInvitationRoute() {
  const { token } = Route.useSearch();
  const navigate = useNavigate();
  const [status, setStatus] = useState<'pending' | 'ok' | 'error'>('pending');

  useEffect(() => {
    (async () => {
      try {
        await authClient.organization.acceptInvitation({ invitationId: token });
        toast.success('Invitation accepted');
        setStatus('ok');
        setTimeout(() => navigate({ to: '/tasks' }), 1000);
      } catch (e) {
        toast.error(messageFor(e));
        setStatus('error');
      }
    })();
  }, [token, navigate]);

  return <div className="p-8">Accepting invitation… ({status})</div>;
}
```

```tsx
// services/mission-control/web/src/components/events/events-viewer.tsx
import { useInfiniteQuery } from '@tanstack/react-query';
import { useVirtualizer } from '@tanstack/react-virtual';
import { useRef, useState } from 'react';
import { api } from '../../lib/api';
import { Button } from '../ui/button';
import { Link } from '@tanstack/react-router';

export function EventsViewer({ filters }: { filters: { kinds?: string; since?: number } }) {
  const q = useInfiniteQuery({
    queryKey: ['events', filters],
    queryFn: ({ pageParam }) => api.events.list({ ...filters, cursor: pageParam as string | undefined, order: 'desc' }),
    initialPageParam: undefined as string | undefined,
    getNextPageParam: (last) => last.next_cursor ?? undefined,
    refetchInterval: 30_000,
  });

  const events = q.data?.pages.flatMap((p) => p.events) ?? [];
  const parentRef = useRef<HTMLDivElement>(null);
  const v = useVirtualizer({
    count: events.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 96,
  });
  const [expanded, setExpanded] = useState<Set<number>>(new Set());

  if (q.isLoading) return <p>Loading…</p>;
  if (q.error) throw q.error;

  return (
    <div>
      <div ref={parentRef} className="h-[600px] overflow-auto border rounded">
        <div style={{ height: v.getTotalSize(), position: 'relative' }}>
          {v.getVirtualItems().map((vi) => {
            const e = events[vi.index];
            const isOpen = expanded.has(e.id);
            return (
              <div key={e.id} style={{ position: 'absolute', top: vi.start, left: 0, right: 0 }} className="p-3 border-b">
                <div className="flex items-baseline justify-between">
                  <div>
                    <strong>{e.kind}</strong> on{' '}
                    <Link to={`/${e.resource_type}s/$id`.replace('$id', e.resource_id) as any} className="underline">{e.resource_type}:{e.resource_id}</Link>
                  </div>
                  <span className="text-xs text-muted-foreground">{new Date(e.created_at).toLocaleString()}</span>
                </div>
                <div className="text-xs text-muted-foreground">{e.actor_type ?? '—'}:{e.actor_id ?? ''}</div>
                <button className="text-xs underline mt-1" onClick={() => { const s = new Set(expanded); s.has(e.id) ? s.delete(e.id) : s.add(e.id); setExpanded(s); }}>
                  {isOpen ? 'Hide' : 'Show'} payload
                </button>
                {isOpen && <pre className="mt-2 bg-muted p-2 rounded text-xs overflow-auto">{JSON.stringify(e.payload, null, 2)}</pre>}
              </div>
            );
          })}
        </div>
      </div>
      {q.hasNextPage && <Button variant="outline" className="mt-4" onClick={() => q.fetchNextPage()} disabled={q.isFetchingNextPage}>Load more</Button>}
    </div>
  );
}
```
